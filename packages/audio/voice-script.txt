# The voice pack, as data. One line per clip, pipe-delimited:
#
#   key | spoken text | IPA | mode | delivery note
#
# This is the single source of truth for every clip the game plays. Three
# things read it, and that is the point — the list used to live inside
# generate-placeholder-audio.sh, so the script handed to a human recording the
# real pack would have been a second copy, and the two would have drifted:
#
#   scripts/generate-placeholder-audio.sh   macOS `say` stand-in
#   scripts/generate-voice-pack.sh          Amazon Polly, using the IPA below
#   scripts/generate-voice-script-doc.ts    docs/VOICE-SCRIPT.md, for a person
#
# packages/audio/src/manifest.test.ts asserts the keys here are exactly the keys
# the app plays, so a clip cannot be added to the game and forgotten here.
#
# IPA is General Australian English. It is what lets a text-to-speech engine
# produce /s/ rather than "ess", and it tells a human recording the pack exactly
# which sound is wanted.
#
# mode is `vowel` where the macOS stand-in has to cut a vowel out of a whole
# word; it means nothing to Polly or to a person.
#
# --- the sounds -------------------------------------------------------------
# These seven are the ones that go wrong. A consonant said with a vowel after
# it — "tuh" for /t/ — cannot be blended: a child sounding t-a-p gets
# "tuh-a-puh" and never hears "tap". Clip the stops. Stretch the continuants.
ph.s|sss|s||As at the start of "sun". Stretch it: a long hiss, two seconds. No vowel before or after.
ph.a|at|æ|vowel|The SHORT vowel of "cat". Not "ah" (father), not the letter name.
ph.t|tuh|t||As at the start of "tap". Clipped and unvoiced. NO schwa — "t", never "tuh". Little more than a tap of air.
ph.p|puh|p||As at the start of "pig". Clipped and unvoiced. NO schwa — "p", never "puh". A puff, not a syllable.
ph.i|it|ɪ|vowel|The SHORT vowel of "pin". Not "eye", which is the letter name.
ph.m|mmm|m||As at the start of "man". Hum it, lips closed, two seconds. Stretchable and voiced.
ph.f|fff|f||As at the start of "fish". Stretch it: a long unvoiced breath through the lip and teeth. No "fuh".
# --- the letter names -------------------------------------------------------
# Used only where a grown-up is being addressed, and in the parent area. A child
# is never taught these in Level 1, which is why they are kept apart from ph.*.
ln.s|ess|ɛs||The letter NAME. Ordinary, unhurried.
ln.a|ay|æɪ||The letter NAME.
ln.t|tee|tiː||The letter NAME.
ln.p|pee|piː||The letter NAME.
ln.i|eye|ɑe||The letter NAME.
ln.m|em|ɛm||The letter NAME.
ln.f|ef|ɛf||The letter NAME.

# Tricky words: not decodable, taught whole. `as` and `is` end in a /z/ sound
# despite the letter s, which is exactly why they are not in the decodable list.
wd.i_pronoun|I|ɑe||The word "I", not the letter name. Whole word.
wd.the|the|ðə||Unstressed, as in ordinary speech: "thuh", not "thee".
wd.a_word|a|ə||Unstressed "uh", as in "a cat". Not the letter name "ay".
wd.as|as|æz||Ends in a Z sound. Say "az", not "ass".
wd.is|is|ɪz||Ends in a Z sound. Say "iz", not "iss".
# --- what the game says to the child ----------------------------------------
# Warm, unhurried, as if sitting beside them. Never brisk, never teacherly.
# These play on every task, hundreds of times — read them plainly enough that
# they do not grate on the fiftieth hearing.
ui.which_says|Which one says|||Rising, as a question continuing — a sound follows it.
ui.find_letter|Find the letter that says|||Rising, as a question continuing — a sound follows it.
ui.build_word|Build the word|||Gentle instruction. A word follows it.
ui.tap_picture|Tap the picture|||Gentle instruction.
ui.listen_again|Listen again|||Patient, never exasperated. A child hears this when stuck.
ui.lets_go|Let's go!|||Bright. The start of a quest.
ui.all_done|All done!|||Warm and final. The end of a quest.
ui.try_this_one|Try this one|||Encouraging, not corrective.
ui.which_sound|Which sound does it make?|||A real question, lightly asked.
ui.find_word|Which word is it?|||A real question, lightly asked.
ui.missing_letter|Which letter is missing?|||A real question, lightly asked.
ui.which_starts|Which picture starts with this sound?|||A real question, lightly asked.
ui.robot_listen|Listen. Which one is it?|||Slight pause after "Listen". Robot sounds follow.
ui.sound_it_out|Tap each letter, then push them together.|||Unhurried. This explains the game.
# --- praise -----------------------------------------------------------------
# Twelve, so a child does not hear the same one twice in a row. Vary them in the
# booth: different energy each time, none of them shouted.
praise.1|Yes!|||Delighted but small. Not a cheer.
praise.2|That's it!|||Warm recognition.
praise.3|Lovely!|||Soft, genuine.
praise.4|You got it!|||Pleased.
praise.5|Well done!|||Sincere, unhurried.
praise.6|Brilliant!|||Bright.
praise.7|Nice one!|||Casual, friendly.
praise.8|Perfect!|||Light, not emphatic.
praise.9|Clever!|||Admiring.
praise.10|Good listening!|||Names what they did. Warm.
praise.11|Beautiful!|||Soft.
praise.12|You're reading!|||The best one. Quiet wonder, not a cheer — this is the moment the whole product exists for.
# --- encouragement after a wrong answer -------------------------------------
# A five-year-old reads tone before words. Not one of these may sound
# disappointed, surprised, or patient-in-a-strained-way. Aim for the voice you
# would use if they had got it right and you simply wanted another go.
encourage.1|Nearly! Have another go.|||Light and quick. Never consoling.
encourage.2|Good try. Listen again.|||Matter of fact and kind.
encourage.3|Not that one. Try again.|||Neutral. Absolutely no disappointment.
encourage.4|Let's listen together.|||Companionable — "we", not "you".
